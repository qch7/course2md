# course2md

把课程回放变成可以复习的结构化 Markdown 笔记。转写在本地运行；AI 校对与整理会把转写稿和课堂截图发给你配置的大模型或 Agent。

```
链接 / 视频文件
      │
      ├─ 解析      本地文件，或安装的课程平台插件
      ├─ 转写      faster-whisper（GPU / CPU），空隙回填，多格式输出
      ├─ 画面      全课扫描，筛选课件代表图
      ├─ 校对      只纠错不改写的 AI 校对
      └─ 整理      转写 + 画面 → 课程记录 → 详细版与缩略版笔记
```

## 三种使用形态

| 形态 | 适合 | 启动 |
|---|---|---|
| 本地应用 | 个人使用 | `course2md web` |
| 服务器 | 同学共用、多设备同步 | Docker Compose，见 [服务器部署](deploy.md) |
| 计算节点 | 有显卡或装有 DSH / Codex 的电脑 | `course2md worker`，见 [计算节点](workers.md) |

## 主要特性

- **针对中文课堂调过的转写**：关闭跨段上下文串联、过滤静音幻觉、按时间轴回填被 VAD 吞掉的讲话、响度归一化。
- **两版笔记共用一份课程记录**：详细版保留题干、推导、答案、易错点与课堂截图，缩略版保留关键规则和例题结论；教师要求引用原话，无法辨清的内容集中待核对。
- **画面参考**：本地识别投影区域、合并同页截图，AI 逐张读取代表图并在笔记中配图。
- **整理后端**：DeepSeek Harness、Codex CLI 或任意 OpenAI 兼容接口。
- **课程对话**：继续提问或要求修改，修改同步更新两版笔记与配图压缩包，每次修改保存为一个版本，可查看与恢复。
- **笔记导出与同步**：导出 Anki 卡片或增量同步到 Obsidian，见 [笔记导出与同步](exports.md)。
- **阶段化执行**：每个阶段交给具备相应能力的计算节点，结果按内容保存，可只换模型重新整理而不必重新转写。
- **来源插件**：课程平台由独立插件支持，见 [插件开发](plugins.md)。
