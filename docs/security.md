# 安全与隐私

## 本地应用

- 只监听 `127.0.0.1`。服务只接受回环地址或 `COURSE2MD_ALLOWED_HOSTS` 中的主机名，写操作必须来自同源页面并使用 JSON 请求，其它网页无法借浏览器提交任务或读取结果。
- 课程链接可能带登录凭证。日志与 `job.json` 只记录解析器提供的公开描述，完整链接只保存在输出目录下的 `.course2md/workspace.sqlite3`，请勿分享该目录。
- 默认校验 HTTPS 证书，校验失败时可用 `REQUESTS_CA_BUNDLE` 指定根证书；`COURSE2MD_INSECURE_TLS=1` 只用于在可信网络中排查问题。

## Agent

- DSH 与 Codex 以只读方式运行，材料经标准输入传入，结果由 course2md 保存。
- DSH 在 Windows 上执行命令前会为工作目录授权。若 course2md 在受限的沙箱终端（例如其它 AI Agent 或自动化工具的终端）中启动，授权会以 Win32 错误 5 失败。`course2md doctor` 与网页启动时会提示，在普通 PowerShell 或资源管理器中运行 `start.cmd` 即可，无需给 DSH 开启完全权限。

## 服务器

服务器形态的安全边界见 [服务器部署](deploy.md#安全边界)：所有接口需要登录，课程链接以 `COURSE2MD_SECRET_KEY` 加密保存，普通用户不能读取服务器文件、指定输出路径、运行自定义命令或更换模型接口。

## 插件

插件可以执行任意代码，只安装你信任的插件。服务器不允许从网页安装插件。

## 合规

课程录播通常带有版权声明，仅可用于个人复习；带凭证的回放链接等同登录信息，不要外传。course2md 与解析插件只应访问你本来就有权限的内容，不得绕过权限控制。

漏洞报告方式见仓库中的 `SECURITY.md`。
